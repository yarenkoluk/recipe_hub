# 🍽️ Recipe Hub

A responsive recipe website built with **HTML5** and **CSS3**.

This project demonstrates the evolution of a simple static website into a modern responsive interface by separating the development into two versions.

---

## 🚀 Project Versions

### 📁 v1-html-only
- Built using only HTML5
- Focused on semantic structure
- Basic recipe layout

### 📁 v2-html-css-modern
- Responsive design
- Improved user interface
- Modern CSS styling
- Better visual hierarchy

---

## 🛠️ Technologies Used

- CSS3
